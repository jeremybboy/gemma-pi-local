# Roadmap

## V0: foundation

- One-command installation and process control.
- Local text, image, and WAV conversation.
- Streaming browser UI with media previews.
- Pi health display, doctor, and smoke test.
- Trusted-LAN security boundary and honest validation matrix.

## Candidate V0.2 work

- Validate on the target Pi and fix installation or runtime defects.
- Package deterministic multimodal fixtures and expected capability-level checks.
- Improve cancellation, inference timing, and memory/thermal observations.
- Add a systemd user service only if manual process control proves stable.

## Candidate V1 work

- Optional Behringer capture with explicit input-device selection and recording consent.
- Optional authentication or private-overlay-network guidance.
- Opt-in chat export or persistence with clear storage controls.
- Render outputs from separate local image or audio generators when hardware permits.
- Test additional Pi memory sizes, storage types, and operating systems.

These are options, not commitments. The next version should be selected from actual V0 use rather than feature count.
