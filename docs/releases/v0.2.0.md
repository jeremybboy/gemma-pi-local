# Gemma Pi Local v0.2.0

This release turns the Raspberry Pi experiment into a small, agent-readable
reference stack while preserving its narrow security and evidence boundaries.

## Added

- Model-initiated, one-call web search through loopback-only SearXNG with
  gateway-owned source links.
- Experimental Apple-silicon macOS installation and localhost operation using
  Colima.
- Root agent operating guide and explicit compatibility/evidence matrix.
- `gemma-pi verify --json` for machine-readable installation and runtime checks.
- Optional `verify --json --live` multimodal and agentic-search round trips.

## Validated before release

- Raspberry Pi 5 8 GB: install, doctor, startup, text and multimodal interaction,
  SearXNG availability, and structured Gemma tool calling.
- Apple M3 Pro: install, localhost startup, local text inference, model-initiated
  search, cited text response, browser source cards, and the complete v0.2.0
  live verifier with 13 passes and no failures.

The new machine-readable verifier still requires target-Pi capture before its
Pi compatibility row can be promoted to validated.

## Boundaries

The project remains single-user, unauthenticated, and without TLS or persistent
chat history. Gemma accepts text, image, and WAV input but returns text only.
Search queries and search-engine responses leave the device when Gemma invokes
the optional tool.
